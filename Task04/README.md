# Task 04 - Time Series Forecasting & Regression

This task covers time series forecasting and machine learning regression techniques completed using Google Colab.

## Parts

### Part A - Time Series Forecasting
- Historical stock price analysis
- Data preprocessing
- Stationarity testing using ADF
- Differencing
- ACF and PACF analysis
- ARIMA(0,1,0)
- 30-day stock price forecasting

### Part B - Regression Model Comparison
- Data preprocessing
- Train-test split
- Linear Regression
- Ridge Regression
- Decision Tree Regression
- Random Forest Regression
- MAE, RMSE and R² evaluation
- 5-Fold Cross-Validation
- Actual vs Predicted visualization
- Prediction error analysis

## Tools & Libraries

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Statsmodels
