### Task 02 — Exploratory Data Analysis & Baseline Modeling

Task 02 focuses on analyzing an energy consumption dataset from a steel manufacturing plant and developing baseline regression models.

**Main activities:**

* Dataset inspection and analysis
* Exploratory Data Analysis (EDA)
* Numerical and categorical feature analysis
* Outlier analysis using the IQR method
* Correlation analysis
* Data visualization
* Feature engineering
* Energy consumption analysis by load type
* Hourly energy consumption analysis
* Regression modeling
* Model evaluation using MAE, RMSE, and R²
* 5-fold cross-validation
* Model comparison and selection

**Dataset:**

* 35,040 records
* 17 columns
* Target variable: `Usage_kWh`

**Models evaluated:**

* Linear Regression
* Ridge Regression
* Decision Tree
* Random Forest

**Best baseline model:**

Random Forest based on the 5-fold cross-validation RMSE results.

**Task 02 folder:**
